Remaining Work (US3)

  • No production reward/status components — only test fakes (ScriptedReward, ScriptedEpisodeStatus, TruncateAfterNStepsStatus).
  • Seed / SetOptions are no-ops. Info is never populated.
  • Python StateUpdate.reset does not drive Unity Reset().
  • Single reward/status component (GetComponentInChildren); no aggregation.
