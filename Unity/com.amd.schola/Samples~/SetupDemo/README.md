# Setup Demo

Import from AMD Schola in Package Manager, open **Scenes/ScholaSetupDemo.unity**, and press Play. The cube follows Target through real Schola observations and actions using a deterministic controller. No Python or model is needed. Move Target while playing to see it follow again.

Rebuild with **Tools > AMD Schola > Create Setup Demo Scene**. Stop Play Mode before generating scenes. Duplicate a scene before customizing; reimport can replace sample assets.

For installation, Inspector wiring, adaptation, training, export, and inference see `Documentation~/setup.md` in the package. Import **Training Demo** for the end-to-end learned-policy workflow.
